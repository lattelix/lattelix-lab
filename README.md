# Lattelix Lab

Lattelix Lab — личная публичная платформа: профессиональный профиль, портфолио, собственные продукты, инструменты, игры и публикации. Здесь ведутся общий контекст сайта, продуктовые решения, архитектура и дальнейшая разработка. Знак LL объединяет две угловатые буквы и горный силуэт; имя владельца — Lattelix.

Разные режимы сайта могут иметь собственные композиции, навигацию, пользовательские сценарии, анимации и звук. Они используют общие достоверные сведения и сохраняют быстрый доступ к работам, CV, инструментам и контактам.

## Текущая реализация

Next.js App Router, React, TypeScript, Tailwind CSS, Framer Motion и pnpm. Размещение сайта — Vercel, DNS — Cloudflare.

| Путь | Назначение |
| --- | --- |
| `app/` | Страницы, metadata, sitemap и robots |
| `components/site/` | Общий каркас, сцена, навигация и уведомление о переезде |
| `components/tools/` | Интерфейсы и операции инструментов |
| `components/games/` | Игровые эксперименты |
| `content/site.ts` | Общий контент сайта |
| `lib/` | SEO, публичные GitHub-сигналы и утилиты |
| `public/` | Публичные ресурсы |
| `docs/` | Контекст, решения и очередь работ |

`/designs` содержит четыре прототипа. Полноценная система переключения разных сценариев, Japan и календарный автовыбор находятся в очереди разработки. Фактическая готовность инструментов описана в карте проекта.

## Локальная работа

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Проверки:

```sh
pnpm lint
pnpm typecheck
pnpm build
```

После сборки `pnpm start` запускает production-сервер. Для изменений интерфейса дополнительно проверяются реальные действия в браузере. Исходное состояние проверок и известные ошибки перечислены в [карте проекта](docs/plan.md).
